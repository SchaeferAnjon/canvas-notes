# canvas-notes 界面规范 第三版（草稿）

> 草稿，等用户选方向后合进根目录 `DESIGN.md`。没写到的地方沿用 `DESIGN.md`（字体、字号档、强调色用法、卡片、白板、AI 消息、改动预览、底栏）。
> 原型：`design/v3/proto-a.html`（方向 A 右边竖条）、`design/v3/proto-b.html`（方向 B 一行顶栏），源文件 `design/v3/src/`（`proto.css` 里的变量就是这份规范的变量，可以整段搬进 `packages/design`）。

## 2. AI：右下角，能动手

以主线现在的实现为准（提交 3f47277「AI 只浮在中间栏右下角」）：圆形入口 + 浮窗，头上换引擎，消息里有工具步骤行。下面补的是它动手时的样子和主题下的颜色。

### 2.1 入口和面板

- 入口：中间栏右下角 44 圆形，离中间栏右边和底边各 16，`--pop` 底，`--shadow-up`，图标 18；两个方向一样，右栏开着时它跟着中间栏走，仍在中间栏右下角。浮窗开着时入口加一圈 1.5px `--acc-ring` 内描。悬停提示「AI · ⌘J」在按钮上方。
- 浮窗：392 宽，最高 580（窗口矮时 = 窗口高 − 110），圆角 16，`--pop`，`--shadow-up`，从右下角弹出（透明度和 12px 上移，0.2 秒）；右边 = 竖栏宽（A 56，B 0）+ 右栏宽（开着 420）+ 16，底边在入口上方 10。右栏开着时浮窗贴在右栏左边，不挡网页。
- 让位：浮窗开着时，白板缩到 0.8（缩放原点在工具面板右边，卡片不钻到工具面板底下）；文档类页面右边让出 408，正文不被盖住。
- 从上到下：头 48（「AI」+ 引擎胶囊 +「改动都是提交，可撤回」12 `--t3` + 新对话 + 收起）、「看得到」行、消息区、输入框（提示「跟 Claude Code 说，/ 选命令，@ 引用笔记」，名字跟着引擎换）。
- 引擎胶囊：24 高，`--fill` 底，名字 12/500 + 12 的向下箭头。点开菜单 220 宽、圆角 12、`--pop`、`--shadow-up`：头一行 12 `--t3`「用这台 Mac 上已经登录的」，下面 Claude Code、Codex、Gemini、OpenCode 每行 30 高（左边 12 宽放 `--acc` 勾，名字 13/500，没装的整行 `--t3` 不可点、右边写「没装」）。按「Agent 用自己的图标」，名字前面加各家真标志 14（原型里没画）。
- AI 回答上面一行 11 `--t3` 写是哪个引擎答的。

### 2.2 「看得到」和「能动手」

- 一行，左边固定「看得到」12 `--t3`，右边 chip 换行左对齐（22 高、`--fill` 底、前面 6px `--acc` 小点）：当前白板或文档、右栏开着的网页、选中几张卡、@ 的笔记。
- 后面一颗描边 chip（透明底，1px `--line2`，指针图标 12），写它在这一页能做的动作：
  - 白板：挪卡片、排成列、合并
  - 文档：改写、插入、挪块
  - 右栏网页开着：滚动、选中、剪藏网页（网页排在最前，因为最可能是你要它动的）
  - 首页：整理收件箱、开白板
- 空状态：宋体 22「想让它做什么？」+ 两行说明 + 跟着当前页面换的建议（34 高、圆角 10、`--line2` 描边、图标 14）。

### 2.3 它在动手时你看得到什么

| 东西 | 样子 | 什么时候 |
|---|---|---|
| 区域外圈 | 被操作的区域（白板、文档、右栏网页）内描 2px `--acc-ring` | 从第一步到最后一步 |
| 顶部提示条 | 区域顶部居中，32 高胶囊，`--pop`，`--shadow-up`：8px 紫点呼吸 +「AI 正在整理这块白板」+ 小按钮「停下 esc」 | 同上 |
| AI 指针 | 20 的箭头，`--acc-bg` 填色白描边，右下一个「AI」小胶囊（11/500 白字紫底），每次移动 0.55 秒 | 每去拿一样东西前先移过去 |
| 被拿的东西 | 2px `--acc-ring` 外圈，约 0.5 秒 | 正在挪的卡片、正在选的段落 |
| 剪下的段落 | 左边 3px 紫色竖线 + 段尾「✂ 剪成卡片」黑色小胶囊 | 剪完留着，撤回后消失 |
| 工具步骤行 | 就是现在消息里的步骤行：每步一行 24 高、12px；图标 12：灰点（还没做）→ `--acc` 转圈（在做，字变 `--t1`）→ 绿勾（做完，字 `--t2`）→ 红叉（出错，后面跟原因）→ 划线（停下后没做的） | 整个过程 |
| 停下 | 发送按钮变成方块停止键；esc、提示条「停下」都行；当前这一步做完就停 | 任何时候 |
| 结果 | 一句话 + 改动预览（同 `DESIGN.md`），「撤回」= 反向提交 | 最后 |

- 网页里动手时，右栏没开就先开（算第一步）；网页保持网站自己的颜色，不跟主题变。
- 每次动手不管做完还是停下，已做的部分都是一个提交，底栏「本周 N 次提交」加一。

## 4. 主题

### 4.1 规则

- 六套配色，五个名字：家族灰（浅、深）、纯白（浅）、米白（浅）、纯黑（深）、深海蓝（深）。
- 设置里「跟着系统换浅深」默认开：白天用一套浅色，夜里用一套深色，默认家族灰浅 / 家族灰深。在外观里点一张浅色主题卡 = 换掉白天那套并立刻切到浅色；点深色卡同理。
- 主题变量挂在 `[data-skin="…"]` 上，任何元素都能单独套一套（外观页的小预览就是这么画的）；`<html>` 上同时有 `data-tone="light|dark"`。
- 主题不只换颜色，每套的结构差异也写进变量（圆角、投影、玻璃、纸）：

| 主题 | 结构上的不同 |
|---|---|
| 家族灰 | 两级冷灰，白卡轻阴影（现在这套） |
| 纯白 | 左栏、标签条、白板全白；卡片只描 1px 边、没有投影；当前标签下面 2px 黑线；卡片圆角 8 |
| 米白 | 暖纸色加 5% 纸纹；卡片圆角 12、首页组件 16；文档正文放在一张「纸」上（`--paper` 底、`--paper-sh` 投影、圆角 4、上下留 28） |
| 纯黑 | 全黑底；没有投影，只有细线（`--shadow` 只是一圈 11% 白线）；当前标签下面 2px 白线 |
| 深海蓝 | 窗口底是渐变光（`--bgart`）；左栏、标签条、右栏、卡片、弹层都半透明并加 `--blur`；窗口背景可换「深海光 / 极光照片 / 冰洞照片 / 自己选」，照片一律压暗到字能看清 |
